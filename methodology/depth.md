# 深度方法论（统一描述）

> 本文件是「深度」的**唯一权威定义**，取代散落在 SKILL.md / map_single.md / validate.py
> 里互相冲突的字数要求。核心：**深度 ≠ 字数**。

## 一、判定原则

深度的判定标准是三层，按优先级从高到低：

1. **完整性（首要）**：该字段要求的全部要点 / 子问题是否逐项覆盖。**缺一个要点 = 不合格**，
   无论字数多少。
2. **具体性**：是否落到原文的具体句子 / 段落 / 意象，而非模板套话（「以XX为核心」之类）。
3. **字数兜底（次要）**：见下方「基础下限」。字数达标但要点缺失，仍判不合格。

## 二、基础字数下限（兜底红线，非目标值）

| 字段 | 基础下限 |
|------|----------|
| 单篇 summary | ≥1200 中文字 |
| 单篇 mirror_dialogue 展开 | ≥500 中文字（六要素全覆盖为主） |
| 单篇 quote_analysis | ≥300 字 |
| 单篇 emotion_turning_points | ≥300 字 |
| 学科 analysis | ≥1500 中文字 |
| 学科 counter_evidence | ≥300 字 |
| 全局 mirror_dialogue_chapter | ≥1500 中文字（五部分全覆盖为主） |
| 全局 key_findings | ≥15 条（validate 最低红线 10 条） |

**不设上限**。下限是「最低红线」不是「目标值」。

## 三、自适应说明

- 文本短、内容单薄时，LLM 判断「要点已覆盖」即可，不必硬凑字数。
- 文本长、内容丰富时，自然超过下限。
- **判定核心永远是「要点全覆盖」**，字数只是兜底，防止 LLM 用一句话敷衍。

## 四、各字段的要点清单（完整性判定的依据）

### 单篇 summary（四点缺一不可）
1. 核心主题（这篇写了什么）
2. 思想主旨（作者想表达/证明/解决什么）
3. 文本在整体中的位置（它在文集里的角色）
4. 与他篇的关联（哪些母题/概念/意象在此出现或由此发展）

### 单篇 mirror_dialogue（六要素缺一不可）
1. 对话对象识别（addressee） 2. 代词指认（pronoun_map） 3. 自我称谓变化
（self_naming_change） 4. 自我对话模式（self_talk） 5. 未说出口的话（unsaid）
6. 对话对象移动轨迹（addressee_trajectory）

### 学科 analysis（八要素中的「解释」）
必须回应本学科的核心问题（core_questions），且每条判断落到原文证据（evidence）。

### 全局 mirror_dialogue_chapter（五部分缺一不可）
1. 对话对象谱系 2. 自我称谓变化时间线 3. 自我对话模式分布与交替
4. 沉默考古 5. 对话伦理

### 跨学科 multi_explanations
同一现象的多元解释 ≥8 组，每组 ≥3 种学科透镜 + 各自证据 + 置信度。

## 五、与 validate.py 的关系

- `validate.py` 的字数校验 = **兜底红线**（第二层/第三层）。
- `validate.py` 的字段/结构校验（check_single_mirror_fields / check_mirror_dialogue_chapter /
  check_cross_discipline_multi）= **完整性判定**（第一层）。
- 两者合起来才构成「深度」的完整门禁：先看要点全不全，再看字数兜底。
