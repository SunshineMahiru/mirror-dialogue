# 镜面对话方法论

> 本 Skill 的**核心诉求**，不可省略、不可压缩。把每篇文本视为作者与自我、他人、
> 时间、环境之间的「镜面对话」。

## 一、判定总原则

- 「镜面对话」不是修辞，而是**文本中真实存在的、可定位的对话关系**。每条判断必须
  落到原文位置（段落号），不得空泛。
- 对话对象、代词指认、自我称谓变化、自我对话模式、沉默、轨迹，六者缺一不可。
- 推断处标注「推断」，证据不足标注「证据不足」。

## 二、单篇层面（六要素，`mirror_dialogue` 展开 ≥800 字）

### 1. 对话对象识别（`addressee`）
判定作者在对谁说话：过去的我 / 未来的我 / 某人 / 上帝 / 命运 / 读者 / 物品 / 城市 /
抽象概念。判定依据须写清：是第二人称「你」的指向、呼告、还是隐含读者。

### 2. 代词指认（`pronoun_map`）
「你 / 他 / 她 / 我们」各指谁，**至少 3 处原文例证**，每条附原文与段落号。
- 「你」可能是过去的自己、理想的自己、某个具体的人、泛指读者——必须区分。
- 「他/她」是否用于**自我客体化**（作者把自己当第三者观察）是重要信号。

### 3. 自我称谓变化（`self_naming_change`）
「我 / 自己 / 本人 / 俺 / 笔者 / 你自称 / 我们」如何切换，**至少 3 处变化实例**，
每条说明变化的意义（从「我」到「我们」可能意味着从个体走向共同体，从「我」到「他」
可能意味着客体化）。

### 4. 自我对话模式（`self_talk`）
自我审判 / 自我安抚 / 自我追问 / 自我鼓励如何交替，**四种各至少 1 处具体场景**，
每条附原文与段落号。注意区分：
- 自我审判：自我责备、自我否定、道德责难。
- 自我安抚：自我宽慰、自我鼓励、接受现状。
- 自我追问：向自己发问、质疑自己的前提。
- 自我鼓励：给自己打气、设定目标。

### 5. 未说出口的话（`unsaid`）
沉默分析：从省略号、破折号、断裂句、回避话题中，提炼作者回避表达的内容。
只提炼有文本依据的「回避」，不臆测。

### 6. 对话对象移动轨迹（`addressee_trajectory`）
从谁开始 → 经过谁 → 到谁结束。轨迹本身往往就是情绪/认知的走向。

## 三、全局专章（`mirror_dialogue_chapter` ≥1500 字，五部分缺一不可）

在 HTML 报告新增独立章节 `#mirror-dialogue`，位置在逐篇分析之后、多学科分析之前：

1. **对话对象谱系**（`addressee_spectrum`）：所有对话对象按出现频次与情感强度排序，
   附证据。
2. **自我称谓变化时间线**（`self_naming_timeline`）：按文件顺序，展示
   「我 → 我们 → 他（客体化）」的演化，每阶段附原文证据。
3. **自我对话模式分布与交替规律**（`self_talk_patterns`）：审判 / 安抚 / 追问的分布，
   以及三者如何交替。
4. **沉默考古**（`silence_archaeology`）：从省略号、破折号、断裂句、回避话题中提炼，
   每条附位置。
5. **对话伦理**（`dialogue_ethics`）：作者如何对待「他者」作为对话者——承认 / 工具化 /
   客体化 / 共处。

## 四、深度门槛（硬约束，由 validate.py 闸门拦截）

- 单篇 `mirror_dialogue` 展开 ≥800 字（`map_single.md` 口径）；`validate.py` 用
  `zh_len(flatten(mirror_dialogue))` 校验，阈值 500 字为**最低红线**（未达 800 的，
  实际分析仍应补足）。
- 全局 `mirror_dialogue_chapter` ≥1500 字。
- 六要素 / 五部分缺一即算不合格。
