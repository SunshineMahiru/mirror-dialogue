# 引用分析方法论

> 定义「什么算引用」「来源如何判断」「功能如何判断」。
> **判定交给 LLM（标记层）**，脚本只做精确定位、计数、密度、去重。

## 一、什么算引用（判定规则）

满足**其一**才计入引用总数：

1. **引述动词**在引号前 20 字内出现（说、写道、提到、引用、如、所谓、记得、有人说、
   书上说、曾言、尝云）。
2. **书名号《》或篇名号〈〉**包裹。
3. **引号内容 ≥15 字且含完整主谓结构**（含句内标点，或含常见谓词/系词）。

其余引号内容归入 `emphasis_quotes`（强调 / 专名），**不计入引用总数**。

> 注意：规则 3 的「主谓结构」是语义判断。脚本过去用 `PREDICATE_HINTS` 启发式误判，
> 现已由标记层 LLM 判定，脚本只对判定结果定位与计数。

## 二、来源判断（`source_guess`）

- 只看引号前 50 字上下文，**不看引用文本自身**。
- 分类：自引 / 他人 / 书 / 文章 / 歌词 / 电影 / 网络 / 不明。
- 不明就写「不明」，**不得虚构**。

## 三、功能判断（`function`，禁止套话）

功能：佐证 / 抒情 / 反讽 / 共鸣 / 逃避 / 权威 / 对话 / 装饰 / 自我安慰。

**每条功能必须具体到该引用的上下文**，说明：这条引用**在此处**为何是抒情而非佐证、
它回应了前文的哪一处、改变了什么情绪走向。禁止笼统写「起到抒情作用」「增强感染力」。

## 四、引用分析（`quote_analysis` ≥300 字）

逐条解读引用功能，**不是罗列**，每条结合具体上下文。

## 五、深度门槛

- 单篇 `quotes` ≥8 条（`validate.py` 最低红线为 5 条），每条必须有 `interpretation`（解读）。
- `position` 标注段落号；`source_guess` 不明写「不明」。

## 六、脚本职责边界

`scripts/quotes.py` 只做：读取标记层的引用候选 → `find_position` 精确定位 →
计数、密度、来源分布、去重。**不再用启发式判定「什么算引用」**。
