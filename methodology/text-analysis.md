# 文本分析方法论

> 定义「如何分析一篇文本的语言、情感、主题」。用于标记层（情感转折标记）与分析层
> （语言风格、主题归纳、情感基调深化）。

## 一、语言风格（`style`）

从以下维度分析，**每个判断配原文例句佐证**，禁止套话：

| 维度 | 判定要点 |
|------|----------|
| 叙事类型 | 叙事 / 抒情 / 议论 / 意识流（可混合，标注主导） |
| 人称 | 我 / 你 / 他 / 我们；切换的语义（客体化、泛指、对话） |
| 时态 | 现在时 / 过去时 / 祈愿式（如「愿…」）交错 |
| 句法 | 长句密集 / 短句清单式 / 从句嵌套 / 排比 |
| 修辞 | 下定义、比喻、对仗、反证、自我命名（如「苦难资本化」） |
| 标点节奏 | 破折号、省略号、分号的密度与功能 |

## 二、情感基调与转折

- **基调**（`emotion.tone`）：一段话概括整体情绪色彩，如「克制理性为表，深层焦虑为里」。
- **情绪转折点**（`emotion_turning_points`，≥300 字）：标注**至少 3 个转折点**，
  每点给原文位置（段落号）与前后情绪对比。
- 标记层只标记「转折位置」，具体解读留给分析层；脚本的词典法情感得分只是**粗粒度参考**，
  不能替代逐句解读。

## 三、主题归纳

- 主题（`themes`）须落到本篇独有的具体内容，禁止「以 XX 为核心」「体现 XX 主旨」。
- 每个主题给 1 句原文或位置依据。

## 四、分析维度补充（多维透镜清单）

跨文本与单篇均可按需启用，勿平均用力：

- **时间**：日/周/月/年写作量、季节、深夜/清晨倾向。
- **人物**：人名/称谓/关系/共同出现网络。
- **空间**：地点/房间/城市/天气/光线/声音。
- **身体**：睡眠/饮食/疼痛/疲惫/呼吸/心跳。
- **情绪**：焦虑/愤怒/平静/羞耻/希望/孤独/感激。
- **自我指涉**：我/自己/本人/俺/笔者/你/我们。
- **重复母题**：意象/句子/梦/书/歌/路/窗/雨。
- **篇章逻辑**：时间线/主题线/情绪线/空间线/人物线。

## 五、深度门槛

- 单篇 `summary` ≥1200 字（覆盖：核心主题 / 思想主旨 / 在整体中的位置 / 与他篇关联）。
- `emotion_turning_points` ≥300 字。
- 每篇至少 8 条原文引用（见 `quote-analysis.md`）。
